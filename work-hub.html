Firestore 보안 규칙 (마음이톡용 추가분)

Firebase 콘솔 → Firestore Database → 규칙 에 아래 블록을 기존 규칙 안에 추가하세요. 로그인한 사용자만 읽고 쓰며, 본인 글만 지울 수 있습니다.

match /hubTalk/{msg} {
  allow read:   if request.auth != null;
  allow create: if request.auth != null
                && request.resource.data.uid == request.auth.uid;
  allow update: if request.auth != null;   // 고정/해제
  allow delete: if request.auth != null
                && resource.data.uid == request.auth.uid;
}
match /hubChannels/{ch} { allow read, write: if request.auth != null; }
match /hubPrograms/{d}  { allow read, write: if request.auth != null; }
match /hubSessions/{d}  { allow read, write: if request.auth != null; }
match /hubItems/{d}     { allow read, write: if request.auth != null; }
match /hubLedger/{d}    { allow read, write: if request.auth != null; }
match /hubConfig/{d}    { allow read, write: if request.auth != null; }

Firestore·Storage 보안 규칙 (1:1·그룹 대화용)

✅ 이 규칙은 이미 Firebase 콘솔에 등록·게시됐습니다. 대화 상대(members)로 등록된 사람만 그 방을 읽고 쓸 수 있고, 사진·파일 첨부도 센터에 등록된 직원 계정(known())만 올리고 볼 수 있습니다. 아래는 실제로 등록된 내용을 참고용으로 보여드리는 것이니 다시 붙여넣지 않으셔도 됩니다.

① Firestore Database → 규칙 (기존 known() 판정 함수를 그대로 사용합니다)

match /hubRooms/{roomId} {
  allow read, update: if known() && uid() in resource.data.members;
  allow create: if known() && uid() in request.resource.data.members;
  match /msgs/{msgId} {
    allow read: if known() && uid() in get(/databases/$(database)/documents/hubRooms/$(roomId)).data.members;
    allow create: if known() && uid() in get(/databases/$(database)/documents/hubRooms/$(roomId)).data.members
                  && request.resource.data.uid == uid();
    allow update: if known() && uid() in get(/databases/$(database)/documents/hubRooms/$(roomId)).data.members;
    allow delete: if known() && resource.data.uid == uid();
  }
}

② Storage → 규칙 (사진·파일 첨부용, 센터에 등록된 직원 계정만 읽고 쓸 수 있도록)

function signedIn() { return request.auth != null; }
function uid() { return request.auth.uid; }
function isOwnerMail() { return signedIn() && request.auth.token.email == 'bakjinwoo92@daum.net'; }
function hasRoleDoc() { return signedIn() && firestore.exists(/databases/(default)/documents/bjw_roles/$(uid())); }
function hasAcctDoc() { return signedIn() && firestore.exists(/databases/(default)/documents/cms_accounts/$(uid())); }
function known() { return isOwnerMail() || hasRoleDoc() || hasAcctDoc(); }

match /{allPaths=**} {
  allow read, write: if known();
}
